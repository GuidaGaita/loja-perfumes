Como criar o token do GitHub (uma vez só)
  1. Abra github.com/settings/personal-access-tokens/new
  2. Em Repository access, escolha Only select repositories e marque loja-perfumes.
  3. Em Permissions → Repository permissions, coloque Contents em Read and write.
  4. Em Expiration, escolha a validade (o painel avisa quando estiver perto de vencer).
  5. Clique em Generate token e cole o código abaixo.

O token é guardado cifrado só neste navegador, e a senha é o que o destranca. Quem não tem o token não consegue alterar o site, mesmo abrindo esta página. Em outro aparelho será preciso cadastrar de novo.
